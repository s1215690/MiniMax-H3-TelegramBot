H3 VRAM Master v0.21.1

Release scope:
- H3VM Core: MODEL execution, VRAM management and dual-GPU scheduling.
- H3VM Video VAE: optional dual-GPU video VAE decode controlled from Core.

Release hardening:
- Mode4 sampling begin/end now follows ComfyUI OUTER_SAMPLE lifecycle.
- Sampling Steps Hint is scheduling guidance only; it no longer controls run reset/boundary correctness.
- Normal predictor startup no longer creates a temporary step_index coordinate history before real timestep arrives.
- Dual Video VAE adds a best-effort weight identity guard against primary/secondary VAE mismatch.
- The bundled reference workflow uses the standard BasicScheduler=20 configuration and presets Sampling Steps Hint=20; stale serialized VAE switch data has also been removed.

Release packaging:
- Removed the unstable all-in-one Master Loader product path.
- Kept only Core + optional Video VAE infrastructure.
- Added Core-controlled Dual-GPU VAE switch.
- Restored label-only Chinese / English UI translation.
- Plugin import remains lazy and does not patch standard ComfyUI loader behavior until H3VM is actually used.
- Release filenames are ASCII-only to avoid ZIP filename mojibake on Windows.
- Reference workflow is included as 01_H3VM_Core_Reference_Workflow.json.
- Static/API compatibility baseline documented for ComfyUI v0.35.0.
